# Generación de Código Intermedio

Presentación web para `Compiladores`, construida a partir del archivo:

- `C:\Users\enzoe\Downloads\20240516-Generación de Código Intemedio -  KM-GY.pptx`

La versión web toma el contenido del PPT original, pero lo presenta con la línea visual de `Exposición 2` para evitar una copia directa del diseño.

## Archivos

- `index.html`: visor principal.
- `styles.css`: interfaz del visor.
- `script.js`: genera automáticamente las diapositivas web a partir del texto extraído.
- `slides-export/`: imágenes exportadas de las 97 diapositivas.
- `slide-text.js`: texto extraído del PPT y embebido para que funcione abriendo `index.html` directamente.

## Uso

Abrir `index.html` en el navegador.

## Nota

Las láminas que dependen mucho de figuras, diagramas o capturas del libro conservan un enlace y, cuando conviene, una referencia visual al slide original.
